# Uber 收据批量下载（Tampermonkey 用户脚本）

在 `riders.uber.com/trips` 注入一个小面板，按日期范围**一键批量下载**自己的行程收据 PDF，用于报销。

- ✅ 按日期范围批量下载，自动翻页加载全部行程
- ✅ 串行下载 + 3~5 秒随机延时 + 分批长休息，避免触发风控
- ✅ 失败自动重试、连续失败自动停机、结果可导出 CSV
- ✅ 多语言界面通用（中 / 英 / 葡 / 西 / 法 / 德 / 日）
- ✅ **全程只读**：不点确认、不提交预约、不调用任何写接口，不上传任何数据

> **本脚本免费开源（MIT），装不上或需要定制可以看 [代办服务与报价](./SERVICE.md)。**
> 服务全程不索取账号密码、不代替登录，操作始终在你自己电脑上完成。

## 安装

> 支持 Chrome / Edge + Tampermonkey。**手机浏览器不支持。**

### 第 0 步：装 Tampermonkey

1. 打开 <https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo>
2. 点「添加至 Chrome」→「添加扩展程序」
3. 装完右上角会出现 Tampermonkey 图标（灰色方块，两个圆点）

> Edge 用户去 Edge 加载项商店搜 "Tampermonkey"，步骤相同。
> 图标被折叠进拼图菜单的话，点一下拼图图标，把 Tampermonkey 钉到工具栏。

### 第 1 步：开启 Chrome 权限（最关键）

Chrome 从 127 版开始收紧了用户脚本权限，**默认是关闭的**。不开这一步会出现两种症状：

- 点安装链接后，只看到一个写着「Script Installation」的空页面，**没有安装按钮**；
- 脚本显示已安装，但在 Uber 页面上什么都不发生。

**1.1 打开开发者模式**

地址栏输入 `chrome://extensions` 回车 → 右上角「**开发者模式 / Developer mode**」→ **打开**

**1.2 给 Tampermonkey 放开权限**

在扩展列表找到 **Tampermonkey** → 点「**详情 / Details**」，检查三项：

| 设置项 | 应设为 | 不设的后果 |
|---|---|---|
| **允许用户脚本** / Allow User Scripts | **打开** | 点链接只出现空壳页（Chrome 138+ 才有此开关） |
| **网站访问权限** / Site access | **在所有网站上** / On all sites | 脚本装上了但不在 Uber 页面执行 |
| 版本号 | **≥ 5.3** | 版本过旧建议在商店点更新 |

> 改完关掉 `chrome://extensions`，回到 Uber 页面按一次 **Ctrl + F5** 强制刷新。

### 第 2 步：安装脚本（三选一）

#### 方式 A：点链接安装（最省事，需第 1 步已完成）

**手动复制**下面这条链接，粘贴到地址栏回车（不要从聊天窗口里直接点，某些情况下会丢参数）：

```
https://raw.githubusercontent.com/BEDUSER/uber-receipts-downloader/main/uber_receipts_batch.user.js
```

Tampermonkey 弹出安装确认页 → 点「**安装 / Install**」→ 关掉标签页。

#### 方式 B：把文件拖进 Tampermonkey（不依赖网络，最稳）

1. 先把仓库里的 `uber_receipts_batch.user.js` 下载到电脑；
2. 地址栏打开 Tampermonkey 管理面板：

   ```
   chrome-extension://dhdgffkkebhmkfjojejmpbldmpobfkfo/options.html#nav=dashboard
   ```

3. 打开资源管理器，把这个 `.user.js` 文件**直接拖进这个页面窗口**；
4. 出现带「安装」按钮的确认页 → 点安装。

#### 方式 C：粘贴源码（保底方案）

1. TM 管理面板 →「**已安装脚本 / Installed Userscripts**」→ 右上角「**+**」新建；
2. 全选删除编辑器里的默认模板；
3. 用记事本打开 `uber_receipts_batch.user.js` → **全选复制 → 粘贴**进编辑器；
4. 按 **Ctrl + S** 保存。

> 粘贴时务必包含首行 `// ==UserScript==` 和末行 `})();`，少一行都不会生效。

### 第 3 步：确认装好了

1. 打开 <https://riders.uber.com/trips>，确认已登录**你自己的** Uber 账号；
2. **页面右上角应出现一个黑色小面板**，标题「Uber 收据批量下载」；
3. 想确认状态：按 **F12** → **Console** → 粘贴回车：

   ```js
   __uberRC.diag()
   ```

   正常返回一个对象，重点看三个字段：

   | 字段 | 期望值 | 含义 |
   |---|---|---|
   | `version` | `"1.0.4"` | 装的版本 |
   | `isTripsPage` | `true` | 当前页被识别为行程页 |
   | `panelMounted` | `true` | 面板已成功插入 |

   - 返回 `undefined` → 脚本没在这页执行 → 回[第 1 步](#第-1-步开启-chrome-权限最关键)检查权限
   - 有对象但 `panelMounted: false` → 面板被遮挡，滚到页面顶部再看

## 使用方法

### 1. 选日期范围

面板上有「开始 / 结束」两个日期框，默认最近 90 天。也可以直接点快捷按钮：

| 按钮 | 范围 |
|---|---|
| 近30天 | 最近 30 天 |
| 近3个月 | 最近 90 天 |
| 今年 | 1 月 1 日 ~ 今天 |
| 近1年 | 最近 365 天 |

### 2. 先点「预览」

点「**预览**」后，面板显示这个范围内扫到多少条行程。**这一步只查询、不下载**，用来确认日期没选错、账号没登错。

如果预览是 **0 条**，先别急着下载，看[常见问题](#预览是-0-条)。

### 3. 点「批量下载」

点下去之后：

- 面板显示「正在下载 3/15」这样的进度，下方有进度条；
- 每笔之间 **3~5 秒随机等待**，每 10 笔**额外长休息 20~35 秒**（防封号的关键，请勿修改延时参数）；
- 文件名为 `Uber_2025-09-05_1a2b3c4d.pdf`（日期 + 行程 ID 前 8 位），保存在浏览器默认下载目录。

> ⚠️ **第一次运行会弹「是否允许本站下载多个文件？」→ 必须点「允许」。**
> 不点允许的话，只有第一个文件能下下来，后面的会被静默拦截。

### 4. 看结果、补下载

跑完后面板底部显示成功 / 失败统计：

- **「导出结果CSV」** —— 导出清单（日期、行程 ID、类型、状态、文件名、失败原因），方便对照报销；
- **「重试失败项」** —— 只针对失败的再跑一遍，不用重下已成功的。

### 5. 中途想停

下载过程中面板会多出「**停止**」按钮。点了之后会等当前这笔完成再停，不会产生半截文件，已完成的部分保留在结果里。

### 关于速度

| 项目 | 默认值 |
|---|---|
| 单笔间隔 | 3~5 秒随机 |
| 长休息 | 每 10 笔休息 20~35 秒 |
| 遇 429 / 403 | 冷却 60 秒后重试 |
| 连续失败 | 4 笔即自动停机 |

所以 **30 笔约需 3~5 分钟，100 笔约需 10~15 分钟**。这是刻意设计：把延时调小会触发 Uber 风控，可能导致账号被临时限制，得不偿失。

### 高级：调整参数

脚本顶部有 `CFG` 配置区（用 TM 编辑器打开即可修改）：

```js
const CFG = {
  delayMinMs: 3000,          // 单笔最小间隔
  delayMaxMs: 5000,          // 单笔最大间隔
  longPauseEvery: 10,        // 每 N 笔长休息
  longPauseMinMs: 20000,
  longPauseMaxMs: 35000,
  maxRetry: 2,               // 失败重试次数
  consecutiveFailLimit: 4,   // 连续失败多少笔自动停
  maxTripCount: 0,           // 0 = 不限；调试时可设 10 只下前 10 笔
  debug: false,              // true = 控制台打印详细日志
};
```

**只建议改 `maxTripCount` 和 `debug`。** 延时改小有封号风险。

## 常见问题

### 点链接后只看到「Script Installation」空页面

这是 Tampermonkey 的安装中间页，说明它拦截到了链接但**没有权限读取脚本内容**。

解决：完成[第 1 步](#第-1-步开启-chrome-权限最关键)的三项设置后重试。仍然不行就用[方式 B](#方式-b把文件拖进-tampermonkey不依赖网络最稳)或[方式 C](#方式-c粘贴源码保底方案)。

### 装好了，但页面上没有面板

1. 确认地址是 `https://riders.uber.com/trips`（脚本只在这个路径生效）；
2. 按 **Ctrl + F5** 强制刷新（**装完没刷新是最常见原因**）；
3. 执行 `__uberRC.diag()`：
   - `undefined` → 脚本没执行 → 检查「网站访问权限」是否为「在所有网站上」
   - `panelMounted: false` → 面板被遮挡，滚到页面顶部

### 预览是 0 条

按顺序排查：

1. **账号不对** —— Uber 的手机号账号和邮箱账号是两套独立数据。点右上角头像确认是不是平时打车那个账号；
2. **去掉 URL 里的活动参数** —— 像 `?csid=...&sm_flow_id=...` 这类是从广告落地页带过来的，直接访问 `https://riders.uber.com/trips` 更干净；
3. **页面显示「您尚未完成任何行程」** —— 说明这个账号确实没有已完成行程，不是脚本的问题；
4. **确认筛选是「所有行程」** —— 页面右上角若有「个人 / 所有行程」，选「所有行程」。

### 下载的文件打不开 / 只有几 KB

说明拿到的是登录页 HTML 而不是 PDF，通常是登录态失效。

脚本会校验文件头，遇到这种情况**直接判为失败并在日志里写明原因，不会存成坏文件**。重新登录 Uber 后点「重试失败项」。

### 浏览器只下了一个文件，剩下的没动静

Chrome 的多文件下载许可被拒了。地址栏左侧点🔒图标 →「网站设置」→ 把「自动下载」改成允许，重跑一次。

### 报错「连续 4 笔失败，已自动停止」

这是保护机制，通常意味着被限流或登录失效。等 10~30 分钟后再试，并确认账号仍处于登录状态。

本仓库是公开的，任何人都能看到完整源码。这是用户脚本的物理限制：**只要安装，源码就一定会落到对方机器上**（Tampermonkey 里可随时查看），做不到对使用者保密。

## 更新与卸载

### 自动更新

脚本头部内置 `@updateURL`，安装后 Tampermonkey 会**每天自动检查一次**新版（前提：[第 1 步](#第-1-步开启-chrome-权限最关键)的权限开着）。也可以在 TM 管理面板手动点「检查更新」。

### 手动更新

用[方式 B](#方式-b把文件拖进-tampermonkey不依赖网络最稳)或[方式 C](#方式-c粘贴源码保底方案)重装一次，直接覆盖旧版。

### 卸载

`chrome://extensions` → Tampermonkey「详情」，或 TM 管理面板里删除脚本条目。

## 技术说明

### 数据来源优先级

1. **`invoiceFiles`** —— 部分地区（如巴西）有正式 invoice 发票 PDF，报销更正规；
2. **`getReceipt`** —— 通用收据，用返回的 timestamp 拼官方 PDF 地址；
3. **DOM 兜底** —— 接口改版时，模拟点击卡片上的收据入口，抓弹窗里的 PDF 链接。

前一级失败自动降级；单笔失败只记录、不中断整轮。

### 行程列表获取

优先用 Uber 网页版自己在用的 `Activities` GraphQL 查询（天然支持 `startTimeMs` / `endTimeMs` 时间过滤 + `nextPageToken` 翻页）；接口不可用时回退到模拟滚动 + 点击「显示更多」。

### 防风控设计

- 所有下载串行，绝不并发；
- 每笔 3~5 秒随机延时，每 10 笔长休息；
- 遇 429/403 冷却 60 秒，同一笔多次限流则放弃；
- 连续 4 笔失败自动停机；
- 下载后校验文件头是否为 `%PDF`，避免把登录页存成坏文件。
